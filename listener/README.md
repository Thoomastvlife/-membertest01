# TikTok 直播留言監聽程式

把直播間裡符合「代號+數量」（例如 `A201+1`）的留言，自動送進後台「直播下單」目前開標中的場次。
一般聊天內容不會送出，也不會出現在留言清單。

> 這個程式使用非官方套件 `tiktok-live-connector`，不是 TikTok 官方 API。
> TikTok 改版時可能暫時失效，也可能不符合平台條款，請自行評估。

## 先在後台取得金鑰

1. 後台 →「直播下單」→ 最下面「自動抓取留言（選用）」→ 按「產生／重設金鑰」。
2. 記下「接收網址」和「金鑰」。
3. 直播前，在後台建立場次並確認它是「開標」狀態（沒有開標中的場次時，送來的留言會被丟棄）。

## 執行方式（擇一）

### 方式 A：GitHub Actions（不需要自己的電腦或主機）

1. 把整個專案（含 `.github/` 與 `listener/`）放在 GitHub 儲存庫。
2. 儲存庫 → Settings → Secrets and variables → Actions，新增：
   - `INGEST_URL`：後台顯示的接收網址
   - `INGEST_KEY`：後台顯示的金鑰
   - `EULER_API_KEY`：選填，套件需要簽章金鑰時才填（看套件文件）
3. 要開播時：Actions →「TikTok 直播留言監聽」→ Run workflow → 填直播主 TikTok 帳號。
4. 單次最長約 6 小時，超過要再按一次；直播結束後可以在 Actions 頁面按 Cancel。

限制：GitHub 的機器是雲端 IP，TikTok 有可能擋掉；私有儲存庫的免費執行分鐘數也有上限。無法保證一定連得上。

### 方式 B：任何可以常駐執行 Node.js 的地方（自己的電腦、主機都可以）

```bash
cd listener
npm install
# macOS / Linux
TIKTOK_USERNAME=直播主帳號 INGEST_URL=後台的接收網址 INGEST_KEY=後台的金鑰 npm start
```

需要 Node.js 20 以上。Windows PowerShell 請先用 `$env:TIKTOK_USERNAME="..."` 設定三個環境變數再執行 `npm start`。

## 它做了什麼

- 連上直播間，收到留言時只留下符合「代號+數量」的（全形＋也可以）。
- 每 2 秒把累積的留言批次送給後台（一次最多 40 則）。
- 同一則留言重送不會重複寫入；斷線會自動重連；後台暫時連不上時會先暫存再重送。
- 後台沒有開標中的場次、或金鑰不正確時，會在畫面上告訴你，並丟棄那一批。

## 常見問題

- **後台沒有出現留言**：確認場次是「開標」、金鑰沒有重設過、留言格式是「代號+數量」，且商品代號在這個場次裡存在。
- **連不上直播間**：直播主要正在直播；套件版本太舊或需要簽章金鑰時也會失敗，請看套件文件。
- **會員沒有自動歸戶**：會員資料要先填 TikTok 帳號；沒綁定的會顯示「未綁定」，可在後台「歸給會員」。
